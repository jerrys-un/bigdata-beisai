面向**职业院校技能大赛「大数据应用与服务」赛项（ZZ052）**的离线闯关学习站。
纯静态、零依赖、无后端，**双击 `index.html` 就能用**，也可以丢到任意 nginx / GitHub Pages 上。

### 给零基础同学的建议路线

1. 先看「基础概念 → 零基础四大件」：Linux 命令、Python/pandas、Java 骨架、MySQL 增删改查，四关打底
2. 再看「基础概念 → 大数据本体」：带 🎬 的看动画，边点边复述每一步
3. 然后「配置实操 → 装完怎么验」：**验证过程的截图就是得分证据**，这个意识要先建立
4. 之后「技能实操」逐类练代码，「赛题实战」按流程与命令清单做整套
5. 考前扫「速查手册」，尤其是「赛场通用」区的开考动作与交卷自查

## 怎么用

```bash
# 方式一：直接打开（最简单）
#   双击 index.html —— 数据文件是 .js 而不是 .json，就是为了绕开 file:// 的 CORS 限制

# 方式二：起个本地服务
python -m http.server 8080
#   然后访问 http://localhost:8080

# 方式三：Docker（仓库里带了 docker-compose.yml）
docker compose up -d     # 访问 http://localhost:8888
```

## 真题示范：不是示意图，是真跑出来的

「赛题实战 → 真题示范」里的第 01 套，是在一台 CentOS 7.9 上**真实敲、真实跑**出来的一遍：

- 每一步的命令与 stdout 都是这次执行的真输出（渲染成终端窗口的样式），**20 步，全程 11 分钟**
- `demo/` 下的 PNG 是 Matplotlib **真画出来的**，HTML 是 Pyecharts **真生成的**交互图
- 每步标了退出码与耗时：退出码 0 才叫跑通，非 0 就是报错
- 最后一步做了 MapReduce 与 Spark 的结果对照（`diff` 一致 ✓）—— 两个引擎算出一样的数才说明前面没错
- 末尾附「你做的时候要在哪些位置截图」

学生照着这个顺序做一遍，第 01 套的流程就算走通了。

## 关于图解动画

仓库里**没有视频文件**，流程类知识（HDFS 写文件、Checkpoint、MapReduce、YARN 提交、Kafka 生产消费）
全部用**自绘 SVG 步骤动画**表达：点「自动播放」看一遍，再手动一步步点，边点边复述每一步在干什么。
这样做的好处是离线可用、体积极小、不牵扯任何版权问题。

## 进度保存在哪

学习进度（看过哪些卡、练习正确率、赛题打勾情况）全部存在**浏览器 localStorage**（键名 `bdstudy_v2`），
不上传任何服务器；换浏览器或清缓存会丢失，这是纯静态站点的取舍。

## 多人使用：账号密码 + 进度隔离

两件事，别混在一起：

**① 能不能进站 —— 靠 Web 服务器的账号密码（局域网自建部署时）**

纯静态网页做不了真正的口令校验（写在前端的口令都能被看到）。真正拦得住的做法是在 nginx 层加 HTTP Basic Auth，进站前浏览器弹框，输错直接 401。仓库 `tools/` 下带了现成脚本：

```bash
cd /data/study-site
./study-users.sh add 张三 123456     # 加人 / 改口令（同名覆盖）
./study-users.sh list                # 看已有账号
./study-users.sh del 张三            # 删账号
./study-users.sh on | off | status   # 开关密码保护
```

口令以 APR1 哈希存进 `.htpasswd`，看不到明文。注意站点是 http，口令在内网明文传输，**只在局域网用**。

**② 学习进度归谁 —— 靠网页右上角的「使用者」**

机房多人共用一台电脑时，各填一次名字（如「张三（计网2401）」），进度就按名字分开存在浏览器 localStorage 里（`bdstudy_v2::<名字>`），互不干扰；老师可以在 `#/me` 页面看到本机每个人的进度概览。

**③ 公网版（GitHub Pages）怎么办 —— 进站口令门**

GitHub Pages 是纯静态托管，没有服务器，做不了 Basic Auth。仓库里内置了一个**进站口令门**：进站先输口令，口令只存 SHA-256 摘要，输对了才渲染内容，解锁状态记在 localStorage 里。

```bash
python sanitize.py --gate 我要的口令     # 生成公开版时设置进站口令（默认 ******）
python sanitize.py --no-gate            # 不要口令，完全公开
python sanitize.py                      # 默认开启，口令 ******
```

**说清楚它的边界**：这层拦得住随手点开链接的人，拦不住懂技术的人（网页里能看到摘要，内容是公开的）。
要真正严格管控，推荐把站点部署到 **Cloudflare Pages**（可以连私有仓库），再用 **Zero Trust → Access** 配访问策略
（邮箱验证码 / 指定邮箱域名 / IP 段），免费且是真正的服务端鉴权。

局域网自建部署时不需要这层，`build.py` 生成的 `gate.js` 默认是 `on: false`（内网免密直接用）。

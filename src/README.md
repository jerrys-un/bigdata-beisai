# src —— 内容源与构建脚本

这里放的是站点数据的**内容源**和构建脚本，改内容从这里改，然后跑 `python build.py` 重新生成 `../data/`。

- `exam_data.py`    赛项规程、十套真题拆解、评分维度
- `skills_data.py`  10 类 / 29 张实操代码卡
- `concepts_data.py` 6 个概念关 + 5 个图解动画（节点 / 连线 / 步骤脚本）
- `build.py`        把上面这些 + 题库与配置注释文本打包成 `data/*.js` 与 `data/*.json`

注意：`build.py` 还会读取赛项题库与配置文件注释版（来自校内资料库导出），
这部分素材不在本仓库里，所以直接 clone 下来跑 `build.py` 会缺输入文件——
仓库里已经带好了构建产物 `data/*.js`，日常使用不需要重新构建。
